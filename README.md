# ホテル収支計画 (Proforma) 作成ツール

サンプルの Excel 収支計画モデル（`template.xlsx`）をベースに、**ブラウザ上の日本語フォームに必要な前提値を入力していくと、収支計画が完成し Excel として出力される**ローカル Web アプリです。

元の Excel は 7 シート・数百の数式が相互参照する精緻なモデルです。本ツールは
**数式やレイアウトを一切壊さず**、ユーザーが入力すべき前提値（ドライバー）のセルだけを
書き換えて出力します。出力ファイルを Excel で開くと全シートが自動再計算され、
サンプルと同じ品質のモデルが完成します。

## セットアップ

```bash
pip install -r requirements.txt
python app.py
```

ブラウザで <http://127.0.0.1:5000> を開きます。

## 出力フォーマットの選択

画面上部で出力フォーマットを選べます。

| フォーマット | 内容 |
|---|---|
| 詳細モデル（全シート・数式付き） | 元サンプルの7シート構成。客室・レストラン・MOD・非配賦・人員計画まで詳細に入力。日本語/英語の出力言語も選択可。 |
| サマリー形式（1枚もの・Naraレイアウト） | `Nara_dhp` をベースにした5年収支サマリー1枚。入力したドライバー値（客室数・稼働率・ADR・成長率・各種率・プロジェクトコスト等）から各行を**数式で自動再計算**。 |

> サマリー形式の「Annual Moxy Fees」ブロックはプリセット値のままです（Moxy/Marriott系の特殊なフィー計算のため）。必要に応じて Excel 上で直接編集してください。

## 使い方

1. 出力フォーマットを選び、フォームの各セクション（客室タイプ、成長率、レストラン、その他収益、非配賦費用、
   マネジメントフィー、プロジェクトコスト、人員計画 など）に前提値を入力します。
   - 起動時にはサンプルの既定値が入っています。変更したい項目だけ書き換えてください。
   - 「％」表記の項目はパーセント値（例: `3` = 3%）で入力します。
2. 画面下部で **出力言語（日本語 / English）** を選びます。
   - 日本語を選ぶと、シート内のラベルが日本語に翻訳されます。
   - English を選ぶと、元から日本語のラベルが英語に翻訳されます。
   - ※ シートのタブ名（Proforma / Rooms など）は数式参照を保つため英語のままです。
3. **「Excelを生成してダウンロード」** を押します。
4. `hotel_proforma_ja.xlsx` / `hotel_proforma_en.xlsx` がダウンロードされます。
   **Excel で開くと自動的に再計算**され、収支計画が完成します。

## 入力できる主な項目

| セクション | 内容 |
|---|---|
| 客室タイプ | タイプ名・室数・広さ・稼働率・客室単価（最大10タイプ） |
| 成長率の前提 | 2〜5年目の稼働率・ADR 成長率 |
| 客室部門 その他費用 | 清掃費・リネン費・消耗品・OTA 手数料 など |
| レストラン部門 | 朝/昼/夕の席数・カバー率・客単価・原価率 |
| その他収益部門 (MOD) | MOD チャージ・テナント賃料・駐車場 など |
| 非配賦費用 | カード手数料・通信費・広告宣伝費・施設管理費・水道光熱費 など |
| マネジメントフィー・オーナー経費 | 各種フィー率・固定資産税・保険・リザーブ |
| プロジェクトコスト | 取得価格・サイネージ・リブランディング費用 など |
| 人員計画 | 客室／レストラン／その他収益／非配賦の各部門の月給・人数 |

## 仕組み

- 入力すべきセルの定義は `fields.py` に一元管理されています（フォーム描画と
  Excel 書き戻しで共有）。
- `app.py` が `template.xlsx` を openpyxl で読み込み、数式セルはそのままに、
  入力値だけを該当セルへ書き込みます。
- `fullCalcOnLoad` を有効化しているため、Excel で開いた瞬間に全シートが再計算されます。

## ファイル構成

```
app.py             Flask アプリ本体（フォーム描画・Excel 生成）
fields.py          入力セルの定義（シート/セル/ラベル/種別）
translations.py    出力ラベルの対訳辞書（日本語 / 英語）
templates/index.html  入力フォーム（日本語 UI）
template.xlsx      元となる収支計画モデル（数式付き）
requirements.txt   依存パッケージ
```
